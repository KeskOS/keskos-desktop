# KeskOS Plymouth Theme

This is the KeskOS BIOS-terminal Plymouth theme. It keeps the boot screen intentionally quiet and shows curated KeskOS boot milestones sent through `plymouth display-message`.

The theme is installed as `keskos` under `/usr/share/plymouth/themes/keskos/`.

The layout is responsive for 1366x768 and 1920x1080 style displays: firmware text stays top-left, the logo stays top-right, and the live boot messages are rendered inside the orange bordered log panel.
