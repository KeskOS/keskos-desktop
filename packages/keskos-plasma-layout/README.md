# keskos-plasma-layout

KeskOS default Plasma panel layout, layout templates, and pinned app launchers.

This package now lives in the consolidated `KeskOS/keskos-desktop` desktop stack repository at `packages/keskos-plasma-layout/`.

## Build

```bash
cd packages/keskos-plasma-layout
makepkg -s --noconfirm
```

## Notes

- Pacman package name stays `keskos-plasma-layout`.
- Source assets live under `src/`.
- Installed Plasma layout template and launcher paths remain unchanged.
