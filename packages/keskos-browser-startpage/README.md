# keskos-browser-startpage

KeskOS browser start page and browser theming assets.

This package now lives in the consolidated `KeskOS/keskos-desktop` desktop stack repository at `packages/keskos-browser-startpage/`.

## Build

```bash
cd packages/keskos-browser-startpage
makepkg -s --noconfirm
```

## Notes

- Pacman package name stays `keskos-browser-startpage`.
- Source assets live under `src/`.
- Installed homepage and browser-theme asset paths remain unchanged.
