# keskos-branding

Shared KeskOS branding assets, icons, and wallpapers.

This package now lives in the consolidated `KeskOS/keskos-desktop` desktop stack repository at `packages/keskos-branding/`.

## Build

```bash
cd packages/keskos-branding
makepkg -s --noconfirm
```

## Notes

- Pacman package name stays `keskos-branding`.
- Source assets live under `src/`.
- Installed asset paths remain unchanged.
