# keskos-quickshell-hud

KeskOS Quickshell HUD and top bar configuration.

This package now lives in the consolidated `KeskOS/keskos-desktop` desktop stack repository at `packages/keskos-quickshell-hud/`.

## Build

```bash
cd packages/keskos-quickshell-hud
makepkg -s --noconfirm
```

## Notes

- Pacman package name stays `keskos-quickshell-hud`.
- Source assets live under `src/`.
- Installed Quickshell config and autostart paths remain unchanged.
