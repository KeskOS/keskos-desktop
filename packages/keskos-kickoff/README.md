# keskos-kickoff

KeskOS customized KDE SimpleKickoff launcher.

This package now lives in the consolidated `KeskOS/keskos-desktop` desktop stack repository at `packages/keskos-kickoff/`.

## Build

```bash
cd packages/keskos-kickoff
makepkg -s --noconfirm
```

## Notes

- Pacman package name stays `keskos-kickoff`.
- Source assets live under `src/`.
- Installed plasmoid paths remain unchanged.
