# keskos-sddm-theme

KeskOS SDDM login theme and packaged default SDDM snippets.

This package now lives in the consolidated `KeskOS/keskos-desktop` desktop stack repository at `packages/keskos-sddm-theme/`.

## Build

```bash
cd packages/keskos-sddm-theme
makepkg -s --noconfirm
```

## Notes

- Pacman package name stays `keskos-sddm-theme`.
- Source assets live under `src/`.
- Installed SDDM theme and default snippet paths remain unchanged.
