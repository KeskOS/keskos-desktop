# keskos-workspace-switcher

KeskOS custom Plasma workspace switcher widget.

This package now lives in the consolidated `KeskOS/keskos-desktop` desktop stack repository at `packages/keskos-workspace-switcher/`.

## Build

```bash
cd packages/keskos-workspace-switcher
makepkg -s --noconfirm
```

## Notes

- Pacman package name stays `keskos-workspace-switcher`.
- Source assets live under `src/`.
- Installed plasmoid paths remain unchanged.
